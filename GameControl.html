Game Control

Game Control measures a team’s play-by-play dominance by calculating their time-weighted average score differential across a game. A positive rating indicates how many points on average a team led by throughout the contest duration:

\[\text{Game Control}_{\text{game}} = \frac{\sum (\text{Score Differential}_i \times \Delta t_i)}{\sum \Delta t_i}\]

\[\text{Season Game Control} = \frac{1}{N_{\text{games}}} \sum_{g=1}^{N_{\text{games}}} \text{Game Control}_g\]

Data Import & Processing

We pull official NFL play-by-play data from 2020 through 2025 using nflreadr::load_pbp() and filter the data to get clean regular season data.

seasons <- 2020:2025

# Fetch Play-by-Play data
pbp_raw <- load_pbp(seasons = seasons)

# Filter completed plays and compute duration between play events
pbp_clean <- pbp_raw %>%
  filter(
    season_type %in% c("REG"),
    !is.na(game_seconds_remaining),
    !is.na(total_home_score),
    !is.na(total_away_score),
    !is.na(home_team),
    !is.na(away_team)
  ) %>%
  arrange(season, game_id, desc(game_seconds_remaining)) %>%
  group_by(game_id) %>%
  mutate(
    home_lead = total_home_score - total_away_score,
    # Elapsed seconds from previous play state
    play_duration = lag(game_seconds_remaining, default = 3600) - game_seconds_remaining,
    play_duration = ifelse(play_duration < 0, 0, play_duration)
  ) %>%
  ungroup()

Game Control Calculation

Here is the actual code for game control calculations. We’ll get home and away game control here so it is easier to get the data into a long form.

# Calculate time-weighted score differential per game for home and away teams
game_control_by_game <- pbp_clean %>%
  group_by(season, game_id, home_team, away_team) %>%
  summarize(
    total_time = sum(play_duration, na.rm = TRUE),
    home_gc = sum(home_lead * play_duration, na.rm = TRUE) / ifelse(total_time > 0, total_time, 1),
    away_gc = -home_gc,
    .groups = "drop"
  )

# Reshape data into long team-game format
team_games <- bind_rows(
  game_control_by_game %>% select(season, game_id, team = home_team, game_control = home_gc),
  game_control_by_game %>% select(season, game_id, team = away_team, game_control = away_gc)
)

# Aggregate across each season
season_game_control <- team_games %>%
  group_by(season, team) %>%
  summarize(
    games_played = n(),
    avg_game_control = round(mean(game_control, na.rm = TRUE), 2),
    .groups = "drop"
  ) %>%
  arrange(season, desc(avg_game_control))

Here are the Top 10 Game Control Teams by Season

for (yr in sort(unique(season_game_control$season))) {
  cat("\n### Season:", yr, "\n\n")
  
  top_10 <- season_game_control %>%
    filter(season == yr) %>%
    slice_head(n = 10) %>%
    mutate(Rank = row_number()) %>%
    select(
      Rank,
      Team = team,
      `Games Played` = games_played,

  print(
    kable(
      top_10,
      format = "markdown",
      align = c("c", "l", "c", "r")
    )
  )
  cat("\n")
}

Adjusted Game Control

Below we calculate the adjusted game control which adjusts for the opponent as well as whether a team is home or away.

Note that code here for calculating the adjusted game score. We first build a matrix with all zeros. The number of rows is the number of games and the number of columns is the number of teams. We then replace some of the zeroes in a row with a \(1\) for the home team of a game and a \(-1\) for the away team of the game. We also add an intercept term to the matrix which is just a column of ones.

calc_adj_gc_scratch <- function(df) {
  teams <- unique(c(df$home_team, df$away_team))
  n_games <- nrow(df)
  
  # Construct design matrix: Home (+1), Away (-1)
  X <- matrix(0, nrow = n_games, ncol = length(teams))
  colnames(X) <- teams
  
  for (i in seq_len(n_games)) {
    X[i, df$home_team[i]] <- 1
    X[i, df$away_team[i]] <- -1
  }
  
  margin <- df$home_gc
  fit <- lm(margin ~ 1 + X)
  
  srs_vec <- coef(fit)
  names(srs_vec) <- gsub("^X", "", names(srs_vec))
  srs_vec[is.na(srs_vec)] <- 0
  
  srs_centered <- srs_vec - mean(srs_vec, na.rm = TRUE)
  
  data.frame(
    team = names(srs_centered),
    season=df$season[1],
   Adj_GC = round(unname(srs_centered), 2),
    stringsAsFactors = FALSE
  )
}

This next set of code is some slickness to run the function above by season and bind the resulting output.

ratings_by_season <- game_control_by_game %>%
  group_split(season) %>%
  map(calc_adj_gc_scratch ) %>%
  bind_rows()

Below we get the sorted values in the model.

for (yr in sort(unique(ratings_by_season$season))) {
  cat("\n### Season:", yr, "\n\n")
  
  top_10 <- ratings_by_season %>%
    filter(season == yr) %>%
    arrange(desc(Adj_GC))%>%
    mutate(Rank = row_number()) %>%
    select(
      Rank,
      season,
      Team = team,
     Adj_game_control=Adj_GC
    ) 
  
  print(
    kable(
      top_10,
      format = "markdown",
      align = c("c", "l", "c", "r")
    )
  )
  cat("\n")
}
